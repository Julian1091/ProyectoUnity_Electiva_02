# Chunky Cat

Chunky Cat es un videojuego móvil 2D desarrollado en Unity.

## Descripción

El jugador controla un gato que debe recolectar comida y evitar objetos peligrosos mientras recorre un escenario de plataformas.

Al alcanzar aproximadamente el 80% de la barra de comida, el gato se transforma en su versión gordita.

## Mecánicas principales

- Movimiento horizontal mediante joystick virtual.
- Salto mediante touch en pantalla.
- Plataformas.
- Objetos positivos y negativos.
- Sistema de vidas.
- Power-ups.
- Transformación del gato.
- Tres niveles con dificultad progresiva.
- Menú principal, pausa, Game Over y victoria.
